# Ændringslog – v22

## Nybygget fra bunden

- Ny HTML-struktur.
- Ny CSS og responsivt layout.
- Ny JavaScript-router og datamodel.
- Ny kortmotor-wrapper.
- Ny Openrouteservice-klient.
- Ny og isoleret localStorage-nøgle.
- Ingen automatisk import eller migrering fra ældre versioner.

## Hovedfunktioner

- Fast topmenu med hovedsider.
- Bred fast venstremenu på computer.
- Lodrette hurtig-handlinger i venstremenuen.
- Nedtælling under hurtig-handlingerne.
- Cover med ur, fuld dato, aktuelt vejr og lokale tips.
- Besøgte campingpladser, ønskeliste, kort og rangliste.
- Ferie Album og Ferie Vagten som separate sider.
- Campingpladsformular, detaljevisning, billeder, noter, tags, seværdigheder og vurderinger.
- Cykelruter med dato, flere cykler, elcykel, start/slut-rækkevidde i fem-minutters intervaller, rutebilleder og billeder ved stop.
- Personer, dyr og cykler kan oprettes og redigeres.
- Egen ikonupload til hurtig-handlinger, stjerner, kortmarkører og rutepunkter.
- Sektioner og menupunkter kan flyttes.
- Backup og manuel import.
