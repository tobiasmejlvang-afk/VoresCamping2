# Ændringslog – Vores Camping v23

## Ferie Vagten

- Tilføjet fem forskellige Ferie-Vagt-figurer:
  - klar til tjeneste
  - på vej
  - kontrol og registrering
  - feriealbum-vagt
  - afslappet feriestemning
- Figurerne er gjort gennemsigtige og indbygget i forside, venstremenu, Ferie Vagten, Ferie Album og indstillinger.
- Ny stor ferieknap med tydelig aktiv/inaktiv status.
- Ny kontroltavle over automatisk opsamling af billeder.
- Ny tretrinsvisning af Ferie Vagtens arbejdsgang.
- Mulighed for at skjule eller vise Ferie-Vagt-figurerne under Indstillinger.

## Openrouteservice

- Opdateret referencepakke fra brugerens `openrouteservice-2.zip`.
- Udvidet JavaScript-klient med:
  - autocomplete
  - geokodning
  - struktureret geokodning
  - reverse geokodning
  - directions GeoJSON
  - GPX
  - snap til vej
  - isokroner
  - matrix
  - POI
  - højdedata
  - optimering
- Tilføjet download af ORS-referencepakken direkte fra indstillingssiden.
- Tilføjet lokal POI-søgning fra Ferie Vagten.

## Design

- Tættere og mere balanceret layout.
- Finjusteret topmenu og bred venstremenu.
- Mere kompakte hurtig-handlinger, nedtælling, kort, lister og formularer.
- Nye sorte og gyldne Ferie-Vagt-detaljer, som stadig matcher appens grønne campingtema.
- Bedre responsive layouts til Windows og Samsung-tablet.
