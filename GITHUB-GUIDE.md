# GitHub-guide – Vores Camping v23

1. Åbn repositoryet til Vores Camping.
2. Slet den eksisterende `docs/`-mappe.
3. Upload den komplette `docs/`-mappe fra v23.
4. Kontrollér, at `docs/.nojekyll` er med.
5. Commit direkte til `main`.
6. Gå til **Settings → Pages**.
7. Vælg **Deploy from a branch**.
8. Vælg `main` og `/docs`.
9. Gem og afvent publiceringen.
10. Test først `status.html` og derefter appens hovedside.

Openrouteservice API-nøglen indsættes under **Indstillinger → Ruteplanlægning**.
